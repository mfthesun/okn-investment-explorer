# ОКН.Индекс v1.0.0

Отдельное приложение практики 3 на неизмененном расчетном ядре НИР2. Каталог четырех объектов с фотографиями, объяснение вкладов пяти групп, интерактивная карта Esri с автономным режимом, два сценария, автоматический рейтинг, экспорт и сброс. Добавлены локальные SVG-иконки и короткие пружинные анимации с поддержкой reduced-motion.

Фото: платформа «Наследие» ДОМ.РФ. Источник указан под снимками и в docs/photo-sources.md; права на снимки не входят в лицензии кода и собственных материалов.

Короткое видео с русскими субтитрами показывает реальные действия приложения, включая два сценария и совпадение ручного расчета с автоматическим. Звука нет. В релиз приложены MP4 и SRT.

Проверки: 14 тестов расчетного ядра, воспроизведение исходных таблиц, фото всех объектов, карта, ошибки, экспорт, reduced-motion и мобильный макет. Ограничения: полный индекс только для четырех пилотов; финансовые параметры условны; доступность поддержки не подтверждается.
