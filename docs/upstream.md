# Происхождение отдельного приложения

ОКН.Индекс опубликован как отдельное учебное приложение в репозитории `mfthesun/okn-investment-explorer` по запросу автора проекта. Он подготовлен из локальной ветки `feat/practice3-okn-app` исходного исследовательского репозитория [nir2-okn-investment-index](https://github.com/mfthesun/nir2-okn-investment-index).

Исходная локальная ревизия перед отделением приложения: `30b723b`, включая разработанное в практике 3 приложение и карту Esri. Публичная исходная ревизия ядра НИР2: `11b9492e186786a2c451af73fd62ecf4bab6bf45`. Код расчета `src/scoring.py`, `src/finance.py` и базовые справочники не изменены. История нового репозитория начинается с самостоятельного снимка; прежние Git-истории, личные рабочие файлы и локальные журналы в нее не перенесены.
