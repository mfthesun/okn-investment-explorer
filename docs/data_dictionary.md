# Словарь полей

## Термины

**Реестровая выгрузка** — структурированный набор сведений об ОКН, находящихся
в неудовлетворительном состоянии, формируемый органом охраны ОКН на основе
ведомственного учёта и воспроизводящий в том числе сведения ЕГРОКН и ЕГРН.
В репозитории это лист «Неуды» файла `data/raw/dataset.xlsx`.

**Сведения ЕИСЖС** — второй источник, лист «Наследие Дом РФ» того же файла:
данные, раскрываемые в единой информационной системе жилищного строительства.

Алгоритм не обращается к ЕГРН и ЕГРОКН напрямую: их сведения используются
в том виде, в каком воспроизведены в реестровой выгрузке.

## Поля реестровой выгрузки

Поля, используемые алгоритмом. Внутреннее имя соответствует ключу в
`src/dataset.py`, исходный заголовок приведён с точностью до фрагмента,
по которому выполняется сопоставление.

| Внутреннее имя | Исходный заголовок | Тип | Назначение |
|---|---|---|---|
| `egrokn` | № ЕГРОКН | строка | идентификатор объекта, ключ записи |
| `name` | Наименование ОКН | строка | справочно; для классификации не используется |
| `address` | Адрес НПА | строка | справочно |
| `category` | Категория | категория | показатель 5.2 |
| `kind` | Вид объекта (по данным ЕГРН) | категория | контроль типа объекта |
| `purpose` | Назначение (по данным ЕГРН) | категория | признак Ф1 фильтра применимости |
| `ownership` | Вид собственности | категория | показатель 2.1, признак Ф2 |
| `holder` | Правообладатель | строка | показатель 2.1, признак Ф3; обезличивается |
| `area` | Площадь (кв.м) | число | показатель 3.3, расчёт CAPEX |
| `cadastral_building` | Кадастровая стоимость здания (руб.) | число | показатель 3.4 |
| `cadastral_plot` | Кадастровая стоимость земельного участка (руб.) | число | показатель 3.4 |
| `material` | Материал конструктивных элементов | категория | показатель 1.2 |
| `decision_date` | Дата решения (акта) об отнесении | дата | определение нормативного режима |
| `protection_subject` | Наличие утверждённого предмета охраны | Да/Нет | контроль полноты |
| `obligation` | Наличие охранного обязательства | Да/Нет | контроль полноты |
| `boundaries` | Наличие утверждённых границ | Да/Нет | контроль полноты |
| `condition_act_date` | Дата составления Акта технического состояния | дата | показатель 1.3 |
| `land_use` | ВРИ ЗУ | строка | показатель 4.4, выбор сценария |
| `lat`, `lon` | Координаты: широта, долгота | число | показатели группы Г4 |

## Известные дефекты выгрузки

Обнаружены при разработке; обрабатываются на шаге 1.

**Разнорегистровое написание.** Одни и те же значения встречаются в разном
регистре: «кирпичные» и «Кирпичные», «частная» и «Частная». Без приведения
к единому регистру распределения считаются неверно.

**Составные значения.** Поле вида собственности может содержать несколько
значений через точку с запятой: «Государственная федеральная; Частная».
Служит признаком Ф2 фильтра применимости.

**Непоследовательные разделители.** В поле правообладателя перечисление
юридических лиц выполнено через точку с запятой и перенос строки, а долевая
собственность физических лиц — через запятую. Разделение по запятой без
предварительной классификации по организационно-правовой форме даёт ложные
срабатывания на наименованиях, содержащих запятую.

**Смещение данных по столбцам.** На листе «Наследие Дом РФ» часть строк
смещена, из-за чего в поле состояния объекта попадают значения формы
собственности. По этой причине скрипт обезличивания выполняет второй,
сплошной проход по всем ячейкам.

**Расхождение с первичными документами.** По ряду объектов значения выгрузки
не совпадают с первичными правовыми актами: дата акта технического состояния,
вид объекта, материал конструкций. При расхождении приоритет имеет первичный
документ.

## Справочник критериев

`data/reference/criteria.json`. Структура: группы с весами, внутри каждой —
показатели с локальными весами и шкалами. Поддерживаются четыре типа шкал.

`categorical` — градации по ключу; значение показателя должно совпадать
с одним из ключей, иначе выбрасывается исключение.

`numeric_desc` — числовые диапазоны, заданные верхними границами, значение
убывает с ростом величины; последний диапазон открыт (`max: null`).

`numeric_bands` — числовые диапазоны с немонотонной шкалой; используется
для площади объекта.

`numeric_asc` — диапазоны, заданные нижними границами, значение растёт
с ростом величины; последний диапазон открыт (`min: null`).

Сумма весов групп равна единице, сумма локальных весов внутри каждой группы
равна единице. При отсутствии значения показателя его локальный вес
пропорционально перераспределяется внутри группы, а группа помечается
как оценённая усечённо.
