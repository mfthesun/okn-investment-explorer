# Устройство приложения

Выбран Python со стандартной библиотекой, HTML/CSS/JavaScript без сборщика. Альтернативы: Streamlit быстрее дает готовые компоненты, но требует дополнительных runtime-зависимостей; отдельный React/FastAPI усложняет сборку и обслуживание. Для четырех объектов stdlib-сервер и статический интерфейс достаточны. Приложение слушает только 127.0.0.1; публичный хостинг не предусмотрен.

`app.py` отвечает за HTTP, чтение локальных файлов и сохранение запусков. `src/scenarios.py` валидирует входы, вызывает исходные finance/scoring и формирует единый результат. Интерфейс не содержит формул CAPEX и ИИП: показывает ответы сервера, строит таблицы, полосы вкладов и интерактивную карту Leaflet. Все исходные данные хранятся локально; Leaflet поставляется локально по BSD-2-Clause. Только включенная подложка Esri загружает внешние тайлы. При ее недоступности сохраняется автономная карта точек. Внешних шрифтов, LLM API и CDN нет.

Изолированы исходные справочники, экспериментальные параметры, сохраненные результаты и документы. Исходные инструкции проекта отсутствовали; пользовательские инструкции соблюдены. Новые файлы добавляются в отдельной ветке. README и .gitignore перед изменением сохранены вне репозитория. НИР2-команды остаются прежними. Псков не изменяется.
