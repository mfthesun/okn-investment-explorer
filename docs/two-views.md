# Два представления приложения

Инвесторское представление открывается по умолчанию (`/?view=investor`). Оно содержит фотографии, площадь, индекс и условные затраты, ограничения отбора, карточку и карту. Администраторское (`/?view=admin`) добавляет параметры модели, ранжирование, тепловую таблицу групп, сравнение сохранённых сценариев и эксперимент устойчивости.

Оба представления используют один результат. Переключение не запускает расчёт, не меняет выбор и не сбрасывает параметры. Вверху указан показанный сценарий; в инвесторской панели раскрываются допущения следующего расчёта. Это представления интерфейса, не роли безопасности. Сервер остаётся локальным.

## Понятность без отчёта

Первый экран объясняет назначение и три действия: выбор объектов, ограничения, сравнение. Справка раскрывает индекс 0–1, условные затраты (CAPEX), простую окупаемость (PP) и сценарий. В интерфейсе используются названия пяти групп вместо кодов G1–G5. Веса объясняются как доли влияния; в карточке показана формула вклада группы. Результат называет лидеров и предлагает изучить документы, не обещая доходность. Отсутствие подходящих объектов сопровождается объяснением.

## Визуализации

- Рейтинг: горизонтальные полосы на общей шкале 0–1, названия, места и точные значения; рядом доступна таблица.
- Группы: тепловая таблица исходных оценок 0–1 до применения весов. Числа читаются независимо от цвета, веса указаны в заголовках. Это не корреляционная матрица.
- Сценарии: подписи вынесены за полосы, убрана минимальная ширина, искажавшая небольшие значения. Пропуски не изображаются нулём.
- Карта и эксперимент устойчивости используют прежние данные и расчёты. Эксперимент явно описан как проверка базового расчёта всех четырёх объектов, независимо от фильтров.

Новые зависимости приложения не добавлены. Расчётное ядро, справочники, API и формат экспорта не изменены. Superdesign проверен, но не использован для генерации: CLI не авторизован, авторизация не менялась. Интерфейс реализован локально с рекомендациями data-visualization и data-storytelling.
