# Короткая видеодемонстрация

Запись от 12.11.2026 показывает реальное приложение с представлениями инвестора и администратора, фотографиями, интерактивной картой и сравнением сценария с базой. Длительность около 1 минуты 54 секунд. Звука нет; краткие русские субтитры объясняют каждое действие.

Видео и отдельный SRT опубликованы вместе с приложением: [релиз v1.1.0](https://github.com/mfthesun/okn-investment-explorer/releases/tag/v1.1.0).

| Фрагмент | Действие |
|---|---|
| Задача | Относительный индекс и четыре пилотных объекта |
| Каталог | Фото, источник «Наследие» ДОМ.РФ, сортировка и сравнение выбранных зданий |
| Карточка | Фотография, даты, параметры и вклад пяти групп |
| Карта | Выбор объекта по метке; точки доступны и без загрузки подложки |
| Администратор | Тепловая таблица оценок пяти групп |
| Сценарий А | Стоимость 150 вместо 100 тыс. ₽/м² |
| Сценарий Б | Приоритет правовых рисков, новый лидер 1574 |
| Сверка | Ручной расчет совпадает с автоматическим |
| История и сравнение | Параметры запусков; база и открытый сценарий, изменение индекса и места |
| Устойчивость | 1000 повторов, частоты не равны вероятности успеха |
| Экспорт и сброс | JSON, CSV, возвращение к базе |
| Проверки | Фактический результат 14 тестов |
| Границы | Четыре полные записи; дальнейшая работа НИР3 |

## Воспроизведение записи

Установите `requirements-dev.txt`, Chromium через `python -m playwright install chromium ffmpeg` либо используйте установленный Chrome и совместимый ffmpeg Playwright. Запустите `python app.py`, затем `python scripts/record_demo.py`. Можно задать APP_URL и BROWSER_EXECUTABLE. Скрипт выполняет действия в реальном браузере и сохраняет WebM, точные тайминги `chapters.json`, SRT и проверочный экспорт в игнорируемой папке `demo-recordings/`.

MP4 формируется из этой записи ffmpeg, без ускорения вычислений и подмены результатов. Субтитры располагаются на дополнительной полосе под изображением, чтобы не закрывать карту и показатели. Старое видео не используется как демонстрация новой версии.
